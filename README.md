# WindowsTopBar
# 🎯 TopBar — выезжающая панель быстрого доступа

> **Beta 1.0** — первая публичная версия

TopBar — это минималистичная выезжающая панель, которая всегда под рукой. 
Висит поверх всех окон вверху экрана, не мешает работе и открывается одним движением мыши.

---

## ✨ Возможности

- 🪟 **Всегда поверх всех окон** — не теряется за другими приложениями
- 🎨 **Полупрозрачная полоска** — 50% в покое, ярче при наведении
- 👆 **Свайп вниз** — потяни за полоску мышью, панель выезжает следом
- 🔄 **Плавная анимация** — доводит до конца или закрывает сама
- ⚡ **Быстрые действия:**
  - CMD (Администратор)
  - Редактор реестра
  - Диспетчер задач
  - Проводник
- 📁 **Случайные ярлыки** с рабочего стола (5 штук, клик = запуск)
- 🔄 **Обновление списка** — кнопка пересканирует рабочий стол
